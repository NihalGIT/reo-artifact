# Experiment registry (REO v1.0.0)

Every check and experiment of the article, with its question, procedure, reference (oracle), metrics, known biases,
command, randomness, outputs, and article section. All are run by `python scripts/run_all.py` (25 steps); each run
writes `results/run_manifest.json` (software versions, seeds, commands, SHA-256 digests of inputs and outputs) and the
log of the full run is `results/run_all.log`. Run times depend on the machine; nothing else should.
